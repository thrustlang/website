# Website Command Templates

<img src= "https://github.com/thrustlang/.github/blob/main/assets/standard-text-separator.png" alt= "standard-separator" style= "width: 1hv;"> </img>

Edit placeholders such as `<version>`, `<slug>`, `<title>`, `<field>`, and `<value>` before running a command.

Run commands from the website repository root.

Use the folder for your platform:

- `linux/`
- `macos/`
- `windows/`

The commands point to the existing scripts under `scripts/` or `documentation/assets/`.
