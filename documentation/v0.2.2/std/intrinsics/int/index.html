std::intrinsics::int (v0.2.2)

Integer intrinsics: overflow checks, saturation, and bit operations.

Latest

Overview

std::intrinsics::int exposes low-level integer operations through intrinsic bindings: overflow-checked arithmetic, saturating arithmetic, and bit manipulations.

Use these when you need defined overflow behavior or direct bit operations not covered by the normal operators.

Source: thrustc/std/v0.2.2/intrinsics/int.thrust

Behavior and Use

Overflow-checked and saturating arithmetic return a result struct with a value and an overflow flag.

Bit manipulation intrinsics map directly to LLVM instructions, so their behavior matches the target platform.

Examples

import std::intrinsics::int;
import std::io;

// Add two counters without overflowing past the type maximum.
fn main() s32 @public {
    var total: s32 = int::saturatingAdd[s32](2147483640, 100);

    io::print("total: %d\n", total);

    return 0;
}
import std::intrinsics::int;
import std::io;

// Choose the larger of two sensor readings.
fn main() s32 @public {
    var high: s32 = int::max[s32](-3, 7);

    io::print("high reading: %d\n", high);

    return 0;
}
import std::intrinsics::int;
import std::io;

// Turn a signed difference into a magnitude.
fn main() s32 @public {
    var magnitude: s32 = int::absolute[s32](-12);

    io::print("magnitude: %d\n", magnitude);

    return 0;
}

Notes

  • These are primitive building blocks; wrap them in checked helpers for normal code.
  • Behavior follows the underlying platform integer instructions.
