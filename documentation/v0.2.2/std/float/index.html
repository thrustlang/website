std::float (v0.2.2)

Parsing of floating-point values from text.

Latest

Overview

std::float parses floating-point values from C strings and TString values into f32, f80, or f64.

parse[T] returns a result struct with the parsed value and a success flag, mirroring the integer parsing helpers.

Behavior and Use

parse[T] returns a result struct with a success flag and supports f32, f80, and f64 targets.

Parsing follows C library rules for format and range; check the success flag before using the value.

Examples

import std::float;
import std::io;

// Turn a Celsius text reading into Fahrenheit and print the whole part.
fn main() s32 @public {
    var celsius: f64 = float::parse[f64]("25.0");
    var fahrenheit: f64 = celsius * 9.0 / 5.0 + 32.0;

    io::print("fahrenheit: %d\n", (fahrenheit as s32));

    return 0;
}
import std::float;
import std::io;

// Parse a single-precision reading and show its whole part.
fn main() s32 @public {
    var value: f32 = float::parse[f32]("3.5");
    var whole: s32 = value as s32;

    io::print("whole part: %d\n", whole);

    return 0;
}
import std::float;
import std::io;

// Parse a reading that may be malformed, checking the result first.
fn main() s32 @public {
    var result := float::parseF64("2.5");

    if !(result->ok) {
        io::print("could not parse\n");
        return 0;
    }

    io::print("value: %d\n", (result->value as s32));

    return 0;
}

Notes

  • Check the success flag before reading the value.
  • Parsing follows the platform floating-point rules for the target.
