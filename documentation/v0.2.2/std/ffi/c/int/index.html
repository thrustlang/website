std::ffi::c::int (v0.2.2)

Raw C bindings for integer text conversion.

Latest

Overview

std::ffi::c::int exposes C conversion functions such as atoi, strtol, strtoll, strtoul, and strtoull.

These return raw C results; check the end pointer or errno when conversion can fail.

Source: thrustc/std/v0.2.2/ffi/c/int.thrust

Behavior and Use

The conversion functions return raw C results and may set errno on failure.

Check the end pointer or errno when a conversion can fail.
